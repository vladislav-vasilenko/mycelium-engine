## implementation

Этап разбит на подэтапы по шагам прежней спецификации. У каждого подэтапа есть раздел «Контракт» с входами и выходами. Общие контракты собраны в [обзоре этапа](../specs/02-terrain-biomes.md#контракты). Код не менялся.

Отличия от прежнего плана:

- Шаг 1 стал подэтапом 02.1. Формулировка «загрузить маленькую карту высот» заменена на «получить карту высот», потому что карта генерируется ([AD-28](../architecture/00-arch.md#ad-28-мир-запекается-из-генератора-на-общей-мировой-сетке)).
- В 02.3 добавлены контракты `TileBounds` и `TileDraw`. Уровни 33 и 17 строятся индексными буферами по вершинам LOD 0, стыки — 16 вариантами индексов по маске краёв после юбок. Добавлен CPU-тест отсутствия щелей.
- В 02.2 добавлен режим `substrate` и сверка отладочных видов с CPU-эталоном.
- Сквозная проверка маршрута перенесена в обзор этапа.

Рассмотренный вариант с разбиением по слоям (quad-tree на CPU, генерация высот в compute, mesh-шейдеры, пиксельное смешивание) принят частично. Взяты контракты между слоями. Генерация высот на GPU отклонена для первого среза: ходьба требует совпадения с треугольниками LOD 0, а шум в Rust и MSL расходится в последних знаках. Эта генерация остаётся в [этапе 08](../specs/08-world-scaling.md). Quad-tree не нужен для плоской сетки 12 × 12 тайлов. Mesh-шейдеры остаются лабораторией [07](../specs/07-shader-labs.md#геометрия-и-детализация).
