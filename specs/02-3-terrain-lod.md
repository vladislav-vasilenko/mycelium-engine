# 02.3. Отсечение и уровни детализации

[К этапу 02](02-terrain-biomes.md) · [К карте этапов](README.md)

**Зависит от** — [02.1. Данные мира и ходьба](02-1-terrain-data.md).

**Результат** — рисуются только видимые тайлы. Уровень сетки 65/33/17 точек на сторону выбирается по экранной ошибке. На стыках разных уровней нет щелей.

**По книге** — [подготовка тайлов и структура мира](reading-guide.md#02-ландшафт).

## Контракт

Потребляет из 02.1: `Tile`, вершины `TerrainVertex` уровня LOD 0.

Создаёт:

- `TileBounds { min, max, max_error[lod] }` — границы тайла и наибольшее отклонение высоты каждого уровня от LOD 0. Считаются один раз при запекании.
- `TileDraw { tile: TileId, lod: u8, edge_mask: u8 }` — элемент списка видимых тайлов кадра. `edge_mask` отмечает края, у которых сосед грубее на один уровень.
- Индексные буферы уровней: каждый уровень берёт вершины LOD 0 с шагом 1, 2 или 4. Для каждого уровня есть 16 вариантов по `edge_mask`. Вершинный буфер общий для всех уровней.

Сетка тайлов плоская. Quad-tree и подгрузка тайлов относятся к [этапу 08](08-world-scaling.md).

## Порядок реализации

1. Отсекать тайлы по фрустуму через `TileBounds`. Выводить число видимых тайлов и треугольников в заголовок окна.
2. Добавить уровни 65/33/17. Выбирать уровень по оценке экранной ошибки `max_error` с гистерезисом.
3. Ограничить разницу соседей одним уровнем.
4. Состыковать разные уровни: сначала юбками на краях, затем вариантами индексов по `edge_mask`. Юбки оставить переключателем для сравнения.
5. Добавить отладочный вид выбранного LOD в `TerrainView`, если 02.2 уже готов. Иначе показывать уровень цветом в отдельном режиме.

## Проверка готовности

- CPU-тест для всех уровней и масок: каждая вершина края мелкого тайла лежит на ребре соседнего грубого тайла. Т-образных стыков и щелей нет.
- Разница уровней соседей не превышает одного. При неподвижной камере уровень не меняется от кадра к кадру.
- Для группы контрольных камер глубина с LOD совпадает с LOD 0 в пределах допуска, заданного экранной ошибкой.
- На записи движения вдоль тропы нет открытых щелей на стыках LOD. Число видимых тайлов и треугольников по уровням записано в отчёте.
