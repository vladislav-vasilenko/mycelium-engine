# 02.5. Отсечение на GPU, indirect и импосторы

[К этапу 02](02-terrain-biomes.md) · [К карте этапов](README.md)

**Зависит от** — [02.3. Отсечение и уровни детализации](02-3-terrain-lod.md), [02.4. Растительность](02-4-vegetation.md).

**Результат** — мелкие экземпляры отсекаются и получают LOD в compute, кадр рисуется через indirect-аргументы. Дальние деревья заменяются импосторами без заметного скачка силуэта.

**По книге** — [подготовка тайлов и структура мира](reading-guide.md#02-ландшафт). Для пакетного обновления — §16.6.2 (с. 1061) из [маршрута 03](reading-guide.md#03-вода).

## Контракт

Потребляет: группы `Placement` из 02.4, `TileBounds` из 02.3.

Создаёт:

- Видимые списки индексов, сгруппированные по mesh/material/LOD. У каждого списка фиксированная ёмкость и счётчик переполнения.
- Буфер indirect-аргументов: один набор на группу.
- Стадию `compute output → indirect args` в планировщике проходов.

## Порядок реализации

1. Перенести отсечение мелких экземпляров и выбор LOD в compute. Группировать видимые индексы по mesh/material/LOD. Ограничивать запись ёмкостью списка и выводить счётчик переполнения.
2. Отдельным dispatch записывать ограниченное число экземпляров в indirect-аргументы. [Косвенные аргументы Metal](https://developer.apple.com/documentation/metal/specifying-drawing-and-dispatch-arguments-indirectly)
3. Синхронизировать запись с vertex read и indirect read. Сохранить переключатель на прямой instancing для сравнения.
4. Для деревьев последним уровнем LOD сделать импостор — плоскую карточку, запечённую с нескольких направлений, с плавным переходом (dither) на границе уровней.

## Проверка готовности

- Нулевое и максимальное число видимых экземпляров обрабатываются корректно. При переполнении счётчик ненулевой, запись за пределы списка отсутствует.
- Прямой и indirect пути на одной камере дают одинаковый набор видимых экземпляров и одинаковый кадр.
- На контрольных камерах переход дерева в импостор не даёт заметного скачка силуэта.
- В GPU capture видны барьеры между compute и indirect read, стоимость отсечения и число экземпляров по LOD.
