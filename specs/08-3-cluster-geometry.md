# 08.3. Кластерная геометрия

[К этапу 08](08-world-scaling.md) · [К карте этапов](README.md)

**Зависит от** — [08.1. Разбиение мира и стриминг](08-1-world-partition-streaming.md), [02.5. Отсечение на GPU и indirect](02-5-terrain-gpu-culling.md), [02.6. Отсечение перекрытием](02-6-occlusion-culling.md), [лаборатория mesh shading](07-shader-labs.md#геометрия-и-детализация).

**Результат** — фотосканы скал, валунов и стволов с миллионами треугольников рисуются без ручных LOD: меш разбит на маленькие кластеры, GPU каждый кадр выбирает кластеры такого уровня, чтобы треугольник на экране был размером примерно с пиксель. Подход в духе Nanite из Unreal Engine 5, упрощённый для учебного движка.

**По книге** — [асинхронная загрузка и память](reading-guide.md#08-стриминг).

## Контракт

Потребляет: видимые списки и indirect 02.5, Hi-Z 02.6, стриминг 08.1, mesh-шейдеры из лаборатории 07.

Создаёт:

- Офлайн-иерархию кластеров: меш делится на кластеры по ~128 треугольников, группы соседних кластеров упрощаются с сохранением общей границы, получается DAG уровней. У каждого кластера — границы, ошибка упрощения в метрах и ошибка родителя.
- Выбор кластеров на GPU: кластер рисуется, если его ошибка на экране меньше порога (~1 пиксель), а ошибка родителя — больше. Одинаковое правило для соседей гарантирует отсутствие щелей.
- Отрисовку видимых кластеров через object + mesh shaders Metal 4 с отсечением фрустумом и Hi-Z на уровне кластера.
- Стриминг страниц кластеров: грубые уровни всегда в памяти, мелкие подгружаются 08.1 по запросам выбора.

## Порядок реализации

1. **Построение кластеров.** Инструмент сборки (Rust): разбиение на кластеры, группировка, упрощение с замороженной границей группы (quadric error), повтор до одного корня. Начать с одного фотоскана камня CC0 (Poly Haven или ambientCG).
2. **Выбор LOD на GPU.** Compute или object shader обходит иерархию, пишет видимые кластеры. Проверить отсутствие щелей и «двойных» кластеров между соседями.
3. **Отрисовка.** Mesh shader выводит треугольники кластера, фрагментный шейдер — материал 02.2 или свой. Сравнить с instanced indexed отрисовкой тех же камней с ручными LOD по треугольникам, p95 GPU и памяти.
4. **Отсечение.** Frustum и Hi-Z 02.6 на уровне кластера, двухпроходная схема.
5. **Опыт с программной растеризацией.** Для кластеров с треугольниками меньше пикселя — растеризация в compute с атомарной записью глубины и ID в буфер видимости, затем материал по буферу видимости. Сравнить с аппаратным путём на сцене с плотными скалами.
6. **Стриминг.** Страницы кластеров через очередь 08.1, грубые уровни как запас при промахе.

## Проверка готовности

- На контрольной сцене с 50 фотосканами по 1–2 млн треугольников кадр укладывается в цель среза; число треугольников на экране порядка числа пикселей, а не суммы треугольников мешей.
- Нет щелей и мерцания на границах кластеров при медленном приближении камеры.
- Кадр совпадает с эталоном из полных мешей в пределах допуска экранной ошибки.
- Память на GPU держится в бюджете 08.1 при облёте сцены.
