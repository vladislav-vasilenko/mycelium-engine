# 11. Глобальное освещение

[К карте этапов](README.md)

**По книге** — [глобальное освещение](reading-guide.md#11-глобальное-освещение).

## Что такое глобальное освещение

Прямой свет — это лучи, пришедшие в точку от солнца, луны или лампы. Непрямой — свет, который сначала отразился от других поверхностей. Глобальное освещение (GI) — сумма обоих. Без непрямого света тени одинаково серые, предметы будто приклеены к поверхности. В Unreal Engine 5 этим занимается система Lumen.

## Контракт

Потребляет: `SkyState` и свет солнца или луны (04.1, 04.2), материалы с альбедо (02.2), рельеф и экземпляры (02.1, 02.4), источники свечения грибов (04.4).

Создаёт:

- Карту видимости неба рельефа (horizon map): какая часть неба видна из точки. Запекается с рельефом, обновляется при стриминге 08.
- Экранное затенение (GTAO) для мелких деталей.
- `IrradianceVolume` — сетку проб освещённости вокруг игрока (каскады 2, 8, 32 м): для каждой пробы облучённость по направлениям и видимость, чтобы свет не протекал сквозь стены.
- Пробы отражений и экранные отражения (SSR) для воды и мокрых поверхностей.
- Общий вход для шейдеров: «непрямой свет в точке с нормалью».

## Порядок реализации

1. **Видимость неба.** Для рельефа запечь карту горизонта: в 8–16 направлениях угол, под которым из точки видно небо. Свет неба умножается на видимую долю. Добавить GTAO в экранном пространстве. Овраги и подножия скал становятся темнее, открытые места светлее.
2. **Пробы освещённости.** Сетка проб вокруг игрока, каскады плотности. Каждая проба собирает свет со всех направлений: сначала растеризацией маленькой кубической карты, затем лучами по структурам ускорения Metal (DDGI). Хранить облучённость в октаэдрической раскладке и среднюю глубину для проверки видимости. Обновлять несколько проб за кадр, многократные отражения получаются сами за несколько кадров.
3. **Отражения.** SSR для воды и мокрого песка, при промахе — проба отражений или небо. Опыт с трассированными отражениями — из лаборатории 07.
4. **Ночные источники.** Свечение грибов передаётся в пробы как источник света, поэтому ночью оно освещает окружение.
5. **Сравнение.** Режимы: без GI, только видимость неба, полный GI. Отладочные виды: облучённость, видимость неба, пробы. Как исследование — сравнить с экранным GI и подходом surfels (направление Lumen).

## Проверка готовности

- Тест «белая печь»: белые материалы под равномерным небом дают ожидаемую облучённость без потерь и лишней энергии, отклонение ≤ 5 %.
- Тест перетекания цвета: красная стена рядом с белым полом окрашивает пол, на контрольной камере доля красного в пределах ожидаемого диапазона.
- Свет не протекает сквозь стену толщиной 0,3 м между освещённой и тёмной комнатами.
- Изменение света (облако закрыло солнце) отражается в непрямом освещении за ≤ 1 с без мерцания.
- Бюджет GI ≤ 2 мс GPU на M3 Max при 1920 × 1080; режим без трассировки работает на устройствах без её поддержки.
